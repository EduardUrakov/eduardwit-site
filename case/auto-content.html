Автоконтент под ключ

CrewAI (многоагентная система) GigaChat Python n8n Docker

Команда из четырёх ИИ-агентов производит контент-пакет для блога: находит тренд, пишет статью, проверяет факты и готовит SEO-упаковку. На выходе — материал, готовый к публикации.

Бизнес-проблема

Контент-маркетинг — самый дешёвый источник трафика, но самый дорогой по времени. Типичный цикл одного поста:

  • Выбор темы: что сейчас в тренде, по чему есть спрос — анализ занимает час
  • Написание: черновик статьи — 2–4 часа работы копирайтера
  • Проверка: фактчек и редактура — ещё час
  • Упаковка: title, description, ключевые слова, посты для соцсетей — час

Итого 4–6 часов на один пост. При графике «2 поста в неделю» это полноценная рабочая ставка. Малому бизнесу такой бюджет не потянуть — и блог умирает на третьей неделе.

Цель решения

Создать систему, которая по одной команде «напиши про X» выдаёт готовый к публикации пакет:

  • Сама находит перспективную тему в заданной нише
  • Пишет структурную статью с подзаголовками (~600 слов)
  • Проверяет себя: спорные утверждения, слабые места, правки
  • Готовит SEO-пакет: title, meta description, ключевые фразы, превью для Telegram, пост для соцсетей
  • Работает на российской модели GigaChat — данные не уходят за рубеж

Архитектура

[Запрос: ниша / тема] → CrewAI (Process.sequential) ↓ Агент 1: Разведчик трендов ── выбирает тему ↓ context Агент 2: Автор статей ────── пишет черновик ↓ context Агент 3: Редактор-фактчекер ─ правки, финальная версия ↓ context Агент 4: SEO-специалист ───── SEO-пакет + итоговый отчёт ↓ [Контент-пакет: статья + title + description + ключи + посты]

Инфраструктура: Python + CrewAI, GigaChat API через litellm-провайдер (OAuth по client_id/secret), n8n для расписания и вебхуков, Docker для развёртывания.

Как это работает

1
Постановка задачи — клиент задаёт нишу или конкретную тему: «n8n для малого бизнеса», «ИИ-инструменты для маркетинга». Это единственный шаг с участием человека.
2
Разведка трендов — первый агент анализирует нишу, предлагает 3 темы и выбирает лучшую с обоснованием: аудитория, конкуренция, потенциал трафика.
3
Написание черновика — автор получает выбранную тему и пишет статью: цепляющий заход, 3–4 раздела с подзаголовками, практические советы, вывод.
4
Фактчек и редактура — редактор ищет спорные утверждения и слабые места, возвращает финальную версию со списком внесённых правок.
5
SEO-упаковка — специалист готовит title (до 60 симв.), meta description (до 160 симв.), 5 ключевых фраз, превью для Telegram и пост для соцсетей. Собирает итоговый отчёт.
6
Доставка — готовый пакет уходит клиенту: в Telegram, Google Docs или прямо в CMS. В продакшене — по расписанию через n8n: например, каждый вторник в 10:00.

Детали реализации

4 агента, 5 задач

Каждый агент — роль с целью и «характером» (backstory). Задачи связаны через context: результат предыдущей становится входом следующей.

GigaChat без утечек

Российская модель через litellm-провайдер. Ключи только в .env, в код и логи не попадают. Подходит компаниям с политикой локализации данных.

Самопроверка

Агент-фактчекер — отдельная роль со «скептичным» промптом. Он возвращает финальную версию и список правок: видно, что именно исправлено.

Гибкая сборка

Нужен пятый агент (например, «аналитик соцсетей») — добавляется за минуты. Модель меняется одной строкой: GigaChat-Max / Pro / Lite.

Ценность для бизнеса

  • Регулярный блог без ставки контент-менеджера: система пишет по расписанию, вы только утверждаете
  • SEO-трафик: каждый пост выходит с готовыми title, description и ключевыми фразами
  • Соцсети из одного источника: превью для Telegram и посты генерируются вместе со статьёй
  • Прозрачность: список правок фактчекера виден — вы знаете, что именно проверено

  • Новости и медиа — черновики по заданным темам с фактчеком
  • B2B-сервисы — экспертные статьи для SEO и рассылок
  • Агентства — конвейер черновиков для клиентов с ручной финальной редактурой
